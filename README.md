# SQL-Sales-Analysis


# Project Overview

This project focuses on analyzing sales data using SQL to generate meaningful business insights.
It includes database creation, data cleaning, querying, aggregation, joins, and analytical reports to understand:

- Sales performance
- Customer trends
- Product performance
- Revenue analysis
- Regional sales insights

The project demonstrates strong SQL concepts useful for Data Analyst and Business Analyst roles.

# Features
- Database creation and table management
- Data cleaning using SQL
- Aggregate functions (SUM, AVG, COUNT)
- Joins (INNER JOIN, LEFT JOIN)
- Grouping and sorting data
- Revenue and profit analysis
- Customer purchase analysis
- Top-selling products identification
- Monthly and regional sales reports

# Technologies Used
- SQL
- MySQL 
- DBMS Concepts
- SQL Workbench / pgAdmin


# Key Insights
- Identified highest revenue-generating products
- Analyzed customer purchasing behavior
- Found peak sales months
- Compared regional sales performance
- Improved understanding of SQL analytical queries
